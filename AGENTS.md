# Project Guidance

This is a personal portfolio website for a digital experience designer.

Positioning:
Digital Experience Designer for Enterprise Visualization, Digital Twin & Sales Enablement.

Core message:
Turn complex systems, data, and business logic into clear, persuasive digital experiences for decision-making and sales enablement.

Design style:
- Premium enterprise technology aesthetic
- Dark mode
- Subtle grid background
- Cyan / blue gradient glow
- Glassmorphism cards
- Data visualization elements
- Minimal but expressive motion
- Avoid cheap cyberpunk, cartoon style, generic SaaS templates

Tech stack:
- React
- Tailwind CSS
- Framer Motion
- lucide-react

Code preferences:
- Componentized structure
- Responsive first
- Clean naming
- No unnecessary dependencies
- Use mock data arrays for projects and capabilities
- Keep content easy to edit
